# نتائج التحقق وحدود الإصدار

التاريخ: 30 أكتوبر 2026. جميع البيانات المستخدمة اصطناعية. هذه نتائج التشغيل المحلي الحالي، وليست إثبات نشر إنتاجي أو استعادة مهمة سحابية جديدة.

## ما تم التحقق منه

| التحقق | النتيجة |
|---|---|
| `npm ci --no-audit --no-fund` من lockfile | نجح |
| `npm run typecheck` و`npm run build` | نجحا |
| `npm test` | 12 حالة منفذة، 12 ناجحة، 0 فشل، 0 تخطي |
| رحلة HTTP `scripts/http-check.mjs` | 56 طلبًا بتوقعات status وتأكيدات بيانات ناجحة |
| RLS: معرفات مباشرة بين عيادتين/عضوية مزورة | رفض/نتيجة خالية حسب نوع العملية |
| ربط مريض من عيادة بموعد من أخرى | رفض بقيد FK مركب |
| طلبا حجز متداخلان متزامنان | قبول واحد ورفض الآخر؛ اختُبر داخل قاعدة محلية ومع طلبَي HTTP |
| ساعات الطبيب/الإجازات/حد الأطباء | رفض محاولات مخالفة مباشرة في القاعدة |
| حفظ المريض بعد خروج ودخول جديد | نجح عبر API، وإنشاء/إعادة تحميل عبر المتصفح |
| وصول المريض وظهوره لحساب الطبيب | نجح عبر جلسات منفصلة؛ الواجهة تستطلع كل 10 ثوانٍ |
| مسودة/version قديم/اعتماد/منع تعديل/تصحيح مؤرخ | نجحت اختبارات API وDB |
| رفض محتوى طبي للاستقبال والمحاسب والمدير افتراضيًا | نجح في API وRLS |
| جزئي ثم كامل/إعادة نفس الدفعة/استرداد/تقرير | نجحت؛ دفتر المقبوضات يطابق مجموع التقرير |
| الخصم وفتح/إغلاق وردية | نجح فحص HTTP، ورفض الخصم من الاستقبال |
| انتهاء الاشتراك | رفض كتابة، واستمرار القراءة والتصدير؛ استعادة التجربة يدويًا |
| مرفقات خاصة | رفع وتنزيل ومطابقة البايتات، رفض استقبال/عيادة أخرى/نوع مزيف/>5MiB/رابط منتهٍ |
| CSRF | رفض Origin خارجي؛ قبول Origin يطابق Host |
| مراجعة Chromium | RTL فعلي، لا overflow أفقي عند 1440 و1024 و390px، إنشاء مريض وتبديل جلسة الدور |
| PDF عربي طويل | 35 دواء اصطناعيًا، 7 صفحات A4؛ وجود الأدوية الـ35 في النص المستخرج، فحص بصري للصفحة الأولى والأخيرة؛ لا قطع أو تداخل للأدوية |
| نسخ/استعادة | snapshot مستقل + استعادة قاعدة ومرفق مع SHA-256؛ أوامر CLI نجحت أيضًا على قاعدة العرض |

ملفات الفحص في `/tmp/shorian-review`: صور الشاشات، PDF والنص المستخرج. الرسائل الخارجية لم تُرسل، والدفع الإلكتروني لم يُنفذ أو يُختبر لعدم وجود مزود مربوط.

## المتبقي قبل اعتبار المتطلبات الموسعة مكتملة

هذه بنود **غير مكتملة**، وليست قدرات مخفية أو نتائج ناجحة مفترضة:

- Supabase Auth والتحقق من البريد واستعادة كلمة المرور والدعوات بالبريد وMFA. إنشاء المستخدم محليًا بواسطة المدير بديل تطوير مؤقت، ولا يثبت ملكية البريد.
- نشر متعدد الخوادم/PostgreSQL خارجي واختبارات حمل وتزامن مستقلة عليه؛ التخزين المحلي يتطلب قرصًا دائمًا. لا يوجد نشر أو رابط معاينة عامة أُنشئ من هذه المهمة.
- ترجمة إنجليزية كاملة: مبدل الاتجاه والعناوين والقائمة موجود، لكن بقية النماذج والنصوص عربية. تخصيص العملة/المنطقة الزمنية/الشعار والاحتفاظ من الواجهة غير مكتمل؛ الافتراضي المنفذ مصر/EGP/Africa/Cairo.
- إعداد أولي guided wizard، والتحقق من توفر جميع الأوقات في Slot Picker (الحجز الحالي يُدخل الوقت ويرفض التعارض على الخادم)، واختصار Walk-in لغير الحاجزين. يمكن إنشاء مريض وموعد وتسجيل وصوله بالرحلة الحالية.
- استكمال/تعديل كل حقول المريض (تاريخ الميلاد والعنوان والطوارئ) بعد الملف السريع، وقالب طبي قابل للإدارة وتاريخ صحي مستقل للمرضى. الملاحظات والحساسية الحالية محفوظة داخل الزيارات، ولا يوجد اقتراح علاجي آلي.
- واجهة تمريض وعلامات حيوية مهيكلة ووحدات/صلاحيات دور nurse، وسير طلب/نتيجة معامل وأشعة مهيكل. الجداول موجودة، لكن وجود الجدول لا يعني تنفيذ الرحلة.
- تقارير التحصيل حسب الطبيب والخدمة ومؤشر المرضى الجدد غير مكتملة؛ المتاح حاليًا الفترة/طريقة الدفع وحالات المواعيد ومتوسط الانتظار وإجمالي المتبقي. فلتر الطبيب يخص قائمة المواعيد؛ التقرير المالي يُعرض للعيادة ككل.
- الباقات حدودها للأطباء والمستخدمين، والتخزين حد محلي ثابت 100MiB للعيادة، وليس حدًا متغيرًا لكل باقة. فواتير الاشتراك ودورة سنوي/شهري وترقية/إلغاء مؤتمتة والتسويات التجارية غير مكتملة.
- بوابة دفع فعلية، Webhook موقع مع deduplication ومعالجة وصول متأخر/غير مرتب، مزود بريد/SMS/WhatsApp وجدولة ومحاولات رسائل. الموجود عقود adapters وحالات صادقة غير مربوطة، وليس تكاملًا عاملًا.
- تفعيل تفضيلات/موافقات التواصل من الواجهة، وسجل إشعارات تاريخي؛ لوحة الإشعارات الحالية تعرض الانتظار الداخلي.
- موافقة دعم طبي محددة المدة غير منفذة؛ الوصول الطبي للمنصة مرفوض بالكامل حاليًا.
- فحص ملفات ضد البرمجيات الخبيثة، نسخ احتياطية مشفرة مجدولة خارج المضيف، سياسات الاحتفاظ/إغلاق الحساب وفق البلد، وتدقيق أمان/امتثال قبل بيانات حقيقية.
- RTL والطباعة راجعا في Chromium؛ Safari وFirefox والأجهزة الفعلية والتقنيات المساعدة تحتاج جولة قبول إضافية.

## قرارات تشغيلية واضحة

المالك ليس طبيبًا تلقائيًا. حساب الطبيب يرى زياراته المصرح بها؛ بيانات المرضى الإدارية داخل العيادة متاحة للأدوار العاملة. الهاتف ليس فريدًا. لا حذف للسجل الطبي المعتمد أو حركات الدفتر من الواجهة. الاشتراك المنتهي يحتفظ بالقراءة والتصدير والطباعة دون حذف البيانات. لا تُسمى قيمة الفواتير تحصيلًا ولا صافي الحركة النقدية ربحًا.
